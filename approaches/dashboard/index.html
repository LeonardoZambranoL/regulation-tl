  1. Set up once (both repos side by side).
git clone https://github.com/LeonardoZambranoL/regulation-tl.git
git clone https://github.com/Certivity/industrial-ai-hackathon.git
cd regulation-tl
git config core.hooksPath .githooks
python -m pip install -r approaches/benchmarking/requirements.txt
  1. Each change: pull, benchmark, rebuild the data, pull again, push.
git pull --rebase
python approaches/benchmarking/bench.py NAME approaches/experiments/NAME/outputs/predictions.json ../industrial-ai-hackathon/cases/dev-rear-lamp/expected.json --index ../industrial-ai-hackathon/regulations/index.json
python approaches/benchmarking/dashboard_rows.py
git pull --rebase
git add approaches && git commit -m "NAME: what changed"
git push

That's it: this dashboard pulls the repo every 15 minutes and shows your pushed results, whatever agent you use. No edit access needed.

Standings

Only one labelled case exists, so a high score can mean fitted to it. Overfit risk is declared by each experiment in its risk.json (what was tuned on the dev case, LLM use), plus automatic flags: an exact match of the gold set is high, no declaration is unknown. Prefer a lower-risk approach when scores are close.
