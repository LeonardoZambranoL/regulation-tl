# In plain words

Claude reads the product specification and chooses several searches for relevant rules. Each search proposes distinct candidate regulations from our local database. Claude inspects promising candidates and explicitly chooses which regulations deserve a full scan. Workers check every clause in those selected regulations, followed by independent verification. A regulation missed during search or rejected during inspection will not be assessed.

# Technical

1. Read the shared LanceDB `clauses` table (26,769 records, 56 regulation/version groups in the current corpus). Validate base versions against the challenge index; never read answer keys.
2. `claude-sonnet-5-5` chooses adaptive native tool searches: at least 4 distinct queries, at most 18 total search/inspection calls over 12 rounds per planning attempt. Embed plain query text using the same shared REST helper as clause ingestion, with `gemini-embedding-2-preview` and 768 dimensions. Validate the shared database model manifest first; no embedding-model fallback.
3. For every query, run exact cosine comparison against all 26,769 clauses and group results into distinct regulation/version candidates. Rank each regulation by the average of its 3 strongest clause similarities and return the top 12 candidates per query. Search results do not automatically enter the scan.
4. Require the planner to inspect opening/scope clauses of every explicit selection. Validate that selected pairs were discovered and inspected, and save reasons/confidence. Then scan every clause in those selected groups using `claude-sonnet-5-5`, 10 workers, at most 12 clauses/14,000 characters per batch, 24,000 context characters. Workers have lexical search/read context tools, up to 4 rounds/8 calls, and may emit only their assigned clauses. Retry failed batches twice.
5. Independently verify proposed requirements using `claude-sonnet-5-5` and the same context tools. Only supported candidates enter predictions; no requirement deduplication. Uncertain/irrelevant assessments are not independently reassessed.
6. Validate the official output schema. Save separate predictions, diagnostics, retrieval trace, Claude cost estimate, and unpriced Gemini request counts. Output size depends on supported candidates and must meet official limits. Spec text only; no product image.
